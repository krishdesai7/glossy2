The York-Toronto-Helsinki Parsed Corpus
of Old English Prose

README


This folder contains the 2003 distribution of the York-Toronto-Helsinki Parsed Corpus of Old English Prose. Both the annotated corpus files and documentation on the annotation system and the search program CorpusSearch, are included. All the documentation is in html format and can be accessed with a web browser. To begin, open the page YcoeHome.htm in your browser. All other files are accessible from there.

Note that this distribution does not include the CorpusSearch program itself. This is a proprietary program and instructions for obtaining it are included on the home page.
